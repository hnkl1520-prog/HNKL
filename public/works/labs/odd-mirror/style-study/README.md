`index.html`을 브라우저로 열면 됩니다. 설치·서버·인터넷 없이 동작합니다. `references/`는 HTML과 함께 보관하세요.

## 이번 범위

실제 얼굴 측정과 분리한 정적 조형 시안 3개입니다. 예시의 수는 캐릭터 유형의 수가 아닙니다. 최신 조합형 그림체는 카메라 앱에 연결했습니다. 조합 화면은 개발용 `test/odd-mirror/component-studio.html`로 옮겼고, 기존 주소는 카메라 시작 화면으로 연결됩니다. 이 폴더의 SVG는 이전 정적 시안 기록입니다. 카메라 앱에는 별도로 헤어·안경을 초기 스캔 후 고정하는 동작을 반영했습니다.

- 01: 옆으로 흐르는 짧은 머리, 가로로 긴 눈, 아래로 좁아지는 턱, 작은 귀. 첫 레퍼런스와 비슷했던 비례·배치·색을 변경했습니다.
- 02: 넓은 볼과 각진 턱, 무거운 눈꺼풀. 헤어와 눈썹의 흐름을 맞추고 코를 길게 내려오는 선으로 정리했습니다.
- 03: 둥근 볼과 큰 눈, 짧은 코. 헤어의 바깥 윤곽·앞머리·관자놀이를 함께 설계했습니다.

모든 수치와 특징은 디자인한 값입니다. 실제 인물의 관측값, 추론 결과, 인식 정확도를 나타내지 않습니다. 레퍼런스 6개는 사용자 제공 원본이며, 페이지에서 개별 확대할 수 있습니다. 첫 번째 원본의 중앙 V 형태를 기본 헤어로 일반화하지 않았습니다.

세 코는 모두 동일한 선 굵기·끝 처리로 그립니다. 코의 길이·폭·기울기만 달라집니다.

## 외형 고정 규칙

- 초기 스캔이 끝나면 헤어 형태·색과 안경 유무·형태를 고정합니다. 스캔 뒤 도착한 분할 결과도 무시합니다.
- 라이브 중에는 헤어/안경 픽셀 분석 및 헤어 보간을 하지 않습니다. 표정과 고개 움직임은 계속 반영합니다.
- 수동 재스캔에서는 id(캐릭터 팔레트)를 유지하고 외형을 다시 읽습니다. 사람이 바뀌면 기존 자동 스캔 동작을 유지합니다.
- 초기 스캔에서 헤어를 얻지 못하면 임의 헤어를 추가하지 않고 ‘헤어 미확인 · 다시 스캔’을 표시합니다. 늦게 준비된 모델이 라이브 외형을 바꾸지 않습니다.
- `node test/odd-mirror/appearance-lock.test.mjs`로 합성 랜드마크 22초 처리 후 외형 불변, 표정 처리 유지, 늦은 응답 차단, 재스캔 색 보존, 새 사람 스캔을 확인했습니다. 실제 카메라 정확도 검증은 아닙니다.

## 확인한 결과 — 2026-09-18

헤드리스 Chrome에서 HTTP와 파일 직접 열기를 검사했습니다.

- 시안 3개와 레퍼런스 6개 로딩.
- 같은 색/각자의 색 전환 및 선택 상태.
- 원본 6개 각각 확대, 닫기, Esc 닫기.
- 390px 화면에서 가로 넘침 없음.
- 파일 직접 열기에서 이미지와 색상 전환 정상, 콘솔 오류 없음.

렌더링한 동일 색/개별 색/모바일 이미지를 직접 확인했습니다. 첫 렌더 후 첫 시안의 헤어 높이를 낮추고, 세 목의 끝 폭·길이를 다르게 정리했습니다. 시각적 평가는 자동 검사 통과와 별개이며, 이 결과는 스타일 제안입니다.
